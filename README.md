# Lapinet — Reversible Motion Research

Public experiments and tutorials in exact lattice motion and reversible particle systems.

## Public demos

- [Atlas of Reversibility](https://alleycatsphinx.github.io/lapinet/noether-h4-62/atlas/index.html) — guided interactive introduction to geometry, H4/E8 constructions, reversible state, transport, and interactions.
- [Reversible Springs V2](https://alleycatsphinx.github.io/lapinet/springs.html) — WebGPU experiment with live springs, flocking, and dynamics.
- [Public research homepage](https://alleycatsphinx.github.io/lapinet/)

## Usage

Serve this directory with python3 -m http.server 8000 and navigate to http://localhost:8000/. Springs V2 requires browser WebGPU support. The Atlas uses browser JavaScript modules.

## Scope

This public project contains only the selected public research pages and their required dependencies, with a clean publication history. Other work is maintained in separate private repositories.
